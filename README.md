A modern, professional desktop Photo Editor built with Python. This project was developed to apply Digital Image Processing concepts using manual algorithms, matrix operations, and a highly interactive Graphical User Interface (GUI).

## ✨ Features
* **Custom Splash Screen:** A professional loading screen with a progress bar.
* **Modern UI/UX:** Built with a "Midnight Ice" dark theme, including hover effects and rounded-like buttons.
* **Manual Algorithms:** Applied core image processing algorithms from scratch using `NumPy` matrices (Grayscale, Histogram Equalization, Sobel Edge Detection, Convolution for Blur and Sharpen).
* **Interactive Tools:** Interactive mouse-based Crop and Add Text tools.
* **Before & After Preview:** A "Press and Hold" button to instantly compare the edited image with the original.

## 🛠️ Tech Stack
* **Python 3.x**
* **Tkinter:** For building the interactive GUI.
* **NumPy:** For manual mathematical matrix operations.
* **OpenCV (cv2):** For advanced computer vision filters.
* **Pillow (PIL):** For image handling and formatting.
